## §1.2.2 Core science-to-technology breakthrough

The core breakthrough of MEMPHIS lies in the integration of hippocampal-inspired computational principles with a self-organising memristive hardware substrate, enabling a new class of ultra-low-power, adaptive computing systems in which memory and computation are co-localised.

This represents a fundamental departure from conventional architectures, where processing and memory are physically and functionally separated. Instead, MEMPHIS implements a two-phase computational paradigm, combining: online, event-driven processing for real-time interaction, and offline replay-driven consolidation for memory optimisation and generalisation within the same physical system.

To ensure both scientific robustness and technological feasibility, the system is developed as a modular and progressively integrated architecture, where: hippocampal computational motifs, plasticity and replay mechanisms, and memristive hardware implementations are validated independently before being combined into more complex configurations.

A decisive validation of the project will be the demonstration that a small-scale memristive spiking network (CA3-CA1 module) can perform associative recall and memory consolidation through replay-driven dynamics, achieving improved task performance after offline processing without additional external input. This experiment establishes that adaptive learning and memory optimisation can emerge directly from intrinsic system dynamics, without reliance on conventional training pipelines.

### Five advances beyond the state of the art

- **Computational paradigm.** Moves from sequential, energy-intensive processing toward distributed, event-driven computation inspired by biological circuits.
- **Learning capability.** Enables continuous and adaptive learning through replay-driven consolidation, addressing catastrophic forgetting without separating training and deployment.
- **Memory optimisation.** Introduces hardware-embedded sleep-like processes, including replay and synaptic scaling, for long-term memory formation and restructuring.
- **Hardware substrate.** Employs self-organising memristive systems as a physically grounded implementation of synaptic plasticity, targeting competitive energy efficiency and high integration density, subject to experimental validation.
- **System-level functionality.** Incorporates biologically inspired modulatory pathways for prioritisation and adaptive memory processing, extending beyond current neuromorphic implementations.

## §1.2.3 Contribution to the long-term vision

By demonstrating a hippocampal-inspired neuromorphic system with integrated learning and memory consolidation, MEMPHIS provides a concrete step toward post–von Neumann computing paradigms, where intelligence emerges from the interaction between computation, memory, and physical substrate.

The proposed system establishes: the scientific basis for replay-driven learning in artificial systems; the technological feasibility of ultra-low-power adaptive hardware; and a scalable framework for future brain-inspired architectures in AI and robotics.

While the present project focuses on a constrained hippocampal module, the principles developed here are directly extendable to more complex cognitive systems. By embedding learning and adaptation within the dynamics of physical hardware, MEMPHIS opens a credible pathway toward energy-efficient, continuously learning, and autonomous intelligent systems.
