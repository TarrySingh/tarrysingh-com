# MEMPHIS — 90-second brief

**Full name (working):** MEMPHIS — a hippocampal · memristive · neuromorphic architecture.

**One-sentence pitch.** A neuromorphic chip that co-locates memory and computation through a self-organising memristive substrate driven by hippocampal-inspired two-phase dynamics — and is the first such system to demonstrate offline replay-driven memory consolidation on physical hardware.

**The science-towards-technology breakthrough.** The integration of hippocampal-inspired computational principles (two-phase processing, bidirectional replay, neuromodulation) with a self-organising memristive hardware platform. This combination enables ultra-low-power operation together with adaptive learning capabilities that are not accessible through conventional architectures.

**The decisive experiment.** A small-scale memristive spiking network (CA3-CA1 module) performs associative recall and memory consolidation through replay-driven dynamics, achieving improved task performance after offline processing without additional external input. This demonstrates that adaptive learning and memory optimisation can emerge directly from intrinsic system dynamics, without conventional training pipelines.

**Five advances beyond the state of the art.**

| # | Dimension | Departure |
| --- | --- | --- |
| I | Computational paradigm | Distributed, event-driven (not sequential, energy-intensive) |
| II | Learning capability | Continuous, replay-consolidated (not training-then-deployment) |
| III | Memory optimisation | Hardware-embedded sleep-like processes (replay + synaptic scaling) |
| IV | Hardware substrate | Self-organising memristive systems (not silicon CMOS only) |
| V | System-level functionality | Biologically-inspired modulatory pathways (prioritisation, adaptive memory) |

**Critical uncertainty.** Whether memristive devices can be matched and stabilised at the precision required by the replay-driven dynamics.

**Closing line.** *Memory and computation, co-localised.*
