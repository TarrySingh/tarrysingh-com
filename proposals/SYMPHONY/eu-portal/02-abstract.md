# Abstract  (≤ 2,000 chars)  ·  1,996

SYMPHONY will establish the first neuromimetic knowledge substrate for software systems: a representation in which modules, functions, tests, commit history and design decisions are encoded as nodes in a multi-scale network whose activation patterns are reconfigured, on demand, by task-specific neuromodulatory signals. A code representation that behaves less like a document and more like a nervous system foregrounding what the engineer's current task needs.

Current approaches hit a structural ceiling. LLM coding agents reach SWE-bench scores above 80 per cent, but independent re-evaluation drops these to single digits or 30 per cent once solution leakage is removed. Static analysis and architecture knowledge graphs capture explicit structure but not the design rationale recognised since Avgeriou et al. (2007) as the hardest tier of software knowledge.

SYMPHONY combines both streams under an organising principle from biology. Three advances: unified extraction of structural, behavioural, historical and rationale layers into one graph-resident substrate for activation-based retrieval; context-dependent activation in which one substrate state surfaces different subnetworks under a task token, using the four-scale neuromodulatory framework of Mei, Muller and Ramaswamy (2022); and a low-bandwidth task-control interface from Siciliano-school haptic shared control, intentionally narrow so behaviour is composable, auditable and bounded.

Five objectives across 36 months deliver a four-layer extraction pipeline (M12), a neuromodulatory reconfiguration mechanism (M18), the low-bandwidth control interface (M24), a 20 per cent F1 lift over LLM and knowledge-graph baselines (M30), and a user study with at least 60 stratified engineers (M33). The consortium pairs Real AI, Newcastle (Ramaswamy), CREATEPRISMA-UNINA (Siciliano) and UP Robotics. SYMPHONY targets TRL 1 to 4 and aligns with EIC Pathfinder for a persistent, task-adaptive, auditable substrate of code understanding.
